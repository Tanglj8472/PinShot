# 标注属性与滚轮编辑验证

本轮修改让选项栏跟随当前编辑对象的种类和样式。鼠标离开对象去操作面板时保留编辑目标，切换工具或开始新标注时清除目标。连续 500 ms 内对同一对象的滚轮修改合并为一步撤销，滚轮小增量累计至一格后生效。

## 自动验证

`python tests/test_annotation_interactions.py`：10 项通过，覆盖空心命中、效果工具优先、擦除区域、拖动、样式编辑、旧对象面板、小滚轮增量及合并撤销重做。

## 实际鼠标验证

- 画矩形后切换椭圆工具，悬停矩形边框并向上滚动三格：矩形线宽由 3 变为 6，椭圆按钮保持选中。
- 从矩形移到面板点 Filled：原矩形变为填充对象。撤销填充后，再撤销一次恢复原始线宽。
- 生成贴图，通过右键菜单开启标注工具栏，新增矩形后拖动边框 30×30：移动新增对象；向上滚动两格：该对象边框变粗。
- Windows PyInstaller 打包成功，运行期间错误日志为空。
