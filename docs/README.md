## 维护约定

- 每篇文档只有一个一级标题，标题层级连续，标题和列表前后留空行。
- 版本差异使用表格，操作步骤使用有序列表，代码块标明语言。
- 命令注明执行目录，项目内链接使用相对路径，不写个人电脑路径。
- 区分当前功能、历史实验和待验证事项，不以 CI 通过替代实机验收。
- 旧迁移清单和重复验收记录已归并，原文可从 Git 历史恢复。
