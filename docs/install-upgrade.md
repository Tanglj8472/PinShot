# 安装、升级与卸载

## 系统要求

| 版本 | 最低系统 | 说明 |
| --- | --- | --- |
| 完整版 | Windows 10 2004 / Build 19041 | OCR 运行库依赖 DXCore |
| Lite | Windows 10 1809 / Build 17763 | 不含 OCR、翻译和 MCP |

仅分发 x64 兼容架构。最低安装门槛不等同于所有对应系统均已完成实机验收，特别是 LTSC 1809；参见[Windows 验收](windows-validation.md)。

## 安装目录

安装包采用当前用户安装，不要求管理员权限。固定目录为：

```text
%LOCALAPPDATA%\Programs\PinShot
```

当前安装程序不显示目录选择页，也不自动沿用旧的自定义安装路径。覆盖安装前会提取新版关闭助手及所需运行库，尝试关闭目标安装目录中的 PinShot，再替换程序文件。关闭失败时中止安装，不强行覆盖占用文件。

历史上安装在其他目录的副本需要单独核对。确认其不再使用后，优先通过对应卸载程序移除，勿直接批量删除不明目录。

## 版本切换与更新

完整版和 Lite 共用安装标识、目录和用户配置，安装其中一版会替换另一版，不支持同时运行。切换到 Lite 不删除已有 OCR 模型或翻译配置。

完整版自动更新选择符合条件的正式 Windows 发布，验证 SHA-256 后安装；损坏缓存会重新下载。预发布版不作为正式自动更新目标，更新不会自动重启 Windows。

Lite 暂不通过完整版通道更新，应手动下载名称带 `-lite` 的对应包，避免被替换成完整版。

## 用户数据

默认配置文件为 `%APPDATA%\PinShot\config.toml`。模型、历史与贴图等数据也位于用户数据目录；独立测试目录可通过环境变量覆盖。

安装、升级与卸载均保留用户数据。旧配置会补充缺失字段，不应为了升级先删除配置。提交问题报告前必须移除密钥和个人内容。

## 卸载与排查

卸载程序会先尝试关闭同一安装目录的应用，再移除程序文件；`unins000.exe` 是正常的卸载程序。需要彻底删除个人数据时，应先备份，再由用户自行处理数据目录。

出现安装问题时，请记录安装包完整文件名、系统内部版本、错误提示和安装日志。只写“企业版”不足以判断兼容性。
