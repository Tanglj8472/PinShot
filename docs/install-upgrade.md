# 安装、升级与卸载

Windows 安装包采用当前用户安装，默认目录为 `%LOCALAPPDATA%\Programs\PinShot`，不需要管理员权限。

覆盖安装时，安装包会先从自身解压新版关闭程序及运行库到临时目录，关闭安装目录内占用文件的 PinShot 进程，确认退出后再替换 EXE/DLL。其他目录的实例不在本次关闭范围内。无法关闭时停止安装，并显示错误，不继续覆盖。

自动更新选择版本号最高、包含 Windows x64 安装包的正式发布，校验下载文件的 SHA-256 后再安装。缓存损坏会重新下载。自动更新保持原程序目录，安装成功后重新启动应用，不自动重启 Windows。

配置默认保存在 `%APPDATA%\PinShot\config.toml`，OCR 模型、历史及贴图数据也位于用户数据目录。安装与卸载均不删除这些数据。旧配置保留原有选项，仅补充缺失的新字段。

卸载时会先关闭同一安装目录的应用实例，再删除程序文件。要清除配置和模型，可在卸载后自行处理用户数据目录。

开发回归测试：`tools/test-windows-upgrade.ps1` 使用独立安装 ID、目录和测试数据，覆盖占用中升级、首次安装、关闭失败、静默重启、自动更新参数与卸载后数据保留。
