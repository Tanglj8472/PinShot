## Smoke 退出码

| 码 | 含义 |
|----|------|
| 0 | 必需条件通过（主窗口 + 设置路径） |
| 1 | 硬失败（窗口/类注册失败等） |
| 2 | 已有实例占用单实例锁 |
| 3 | `--smoke-strict` 且截图热键注册失败 |

CI 使用 `--smoke`（非 strict），允许无托盘/热键冲突环境。
