# SnipClone 产品目标

**Windows 原生截图标注工具。**

| 维度 | 参考 | 本仓库策略 |
|------|------|------------|
| 绘制 / 捕获底层 | PowerToys **ZoomIt**（MIT） | GDI 冻结、DPI/显示器辅助、笔迹采样与资源生命周期；**算法逐项适配**，第一阶段继续 **Direct2D / DirectWrite** 渲染 |
| 界面布局与操作节奏 | **Snipaste** | 框选 → 松手出工具栏 → 可继续调选区 / 批注 → 复制·保存·贴图 |

## 不做什么（当前边界）

- 不同时维护第二套绘制后端；仅当 D2D 路径实测无法满足时才评估替换。
- GraphicsCapture、控件级识别：单独评估后再决定（见 `GRAPHICS_CAPTURE.md`）。
- 荧光笔 / 模糊 / 编号标记：基础工具稳定后再做。

## 核心不变量

1. **底图与批注对象分离**：对象保存类型、坐标、样式、文本；渲染器生成预览与导出图。  
2. **选区 = 屏幕坐标；批注 = 冻结图局部坐标**（随选区原点平移，**不因缩小选区而删除**；选区外暂时不可见，扩大后恢复）。  
3. **导出不含**选中框、手柄、输入框、临时预览。  
4. **一次完整手势 = 一次撤销**；预览 / 复制 / 保存 / 贴图同一套合成。  
5. **选择工具**为对象编辑入口：空白处拖动移动选区；命中图形则移动/缩放；绘图工具激活后内部拖动用于绘制。

模块划分保持：`Capture` · `SelectionOverlay` · `DrawStack` · `AnnotationRenderer` · `Toolbar` · `TextEditor` · `PinWindow`。
