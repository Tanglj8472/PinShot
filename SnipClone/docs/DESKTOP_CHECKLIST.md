# SnipClone 桌面回归清单（P0）

在真实 Windows 桌面执行。CI 仅覆盖无头逻辑（裁切 / 撤销 / 合成去 chrome）。

## 每次构建后（建议）

1. 启动 `SnipClone.exe`，确认热键 `Ctrl+Shift+S` 可用（冲突时应有提示）。
2. 框选 → 松手进入批注：底图可见，工具栏在选区附近且不飞出屏幕。
3. 画笔 / 矩形 / 箭头各一笔 → 复制 → 粘贴到画图/Word，内容与预览一致（无蓝选中框）。
4. 再截一次 → 保存 PNG → 再截一次 → 贴图；三种产物像素内容一致（同源导出）。
5. Esc 取消框选后再次热键，可正常进入。
6. 复制时若剪贴板被占用：应提示且批注窗口不关，可重试。

## 连续稳定性（验收）

- [ ] 连续完成 **30** 次：框选 → 批注 → 复制或 Esc，无空白底图、无崩溃、无残留顶层窗口。

## 导出专项

- [ ] 选中图形后导出：图片中 **无** 蓝色选中框。
- [ ] 拖动中途不导出；松手后导出含最终图形。
- [ ] 复制 / PNG / 贴图三次结果目视一致。

## 失败恢复

- [ ] 保存对话框取消：仍留在批注。
- [ ] 保存到只读路径失败：提示，仍可编辑。
- [ ] 贴图创建失败（若可模拟）：提示，不关闭批注。

## 残留检查

- [ ] 任务管理器无多余 `SnipClone` 进程（主进程除外）。
- [ ] Esc / 导出后无透明全屏挡鼠标层。

## P1 框选与批注

- [ ] 进入批注后拖四边/角手柄可缩小/扩大选区（扩大不超出冻结桌面）。
- [ ] 缩小后完全落在选区外的图形消失；部分相交的保留。
- [ ] 选择工具：命中箭头中段 / 细笔划，不易点中空白角。
- [ ] 选择工具：拖两端点可缩放矩形/椭圆/箭头；移动与缩放各一次撤销。
- [ ] 文字：中文 IME 候选用 Enter 确认时不关闭输入框；候选结束后 Enter 才提交。
- [ ] 文字：失焦提交；双击重编后改 B/I/颜色再提交，样式写入图形。
- [ ] 每种工具：创建 → 修改 → 撤销 → 重做 → 导出。
- [ ] 导出仍无选区蓝框、无裁切手柄。
